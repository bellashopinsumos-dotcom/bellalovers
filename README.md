# BellaLovers ♡

Programa de beneficios de BellaShop. Colores: rosado pastel y dorado discreto. Diseño sencillo para celular.

**Estado:** demostración. Aún no recibe registros reales, no confirma compras ni entrega puntos. No usar para operaciones reales hasta configurar Supabase, SMS, política de datos aprobada y pruebas.

El sitio incluye página de clientas y administrador. Los archivos originales de la versión inicial se conservan en `release/` y se publican con el flujo GitHub Pages cuando quede habilitado.

## Qué falta para operar con datos reales

- Base de datos Supabase separada y seguridad probada.
- Verificación de celular por SMS.
- Administradores autorizados y política de datos legal aprobada.
- Catálogo de premios e inventario real con condiciones económicas.
- Pruebas completas antes de abrir inscripciones.
